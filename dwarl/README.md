# DWARL Python package

This package provides the `dwarl` command, MuJoCo simulation, policy training
and evaluation, and the local dashboard server. The workspace installs it in
editable mode, so changes under `src/dwarl/` are picked up by `pixi run dwarl`.

See the [DWARL documentation](https://nobleo.github.io/dwarl/) for setup and usage.
